# DEBTPRICE

Маркетинговый сайт платформы долговых активов. Первая сборка по предоставленному макету: навигация, первый экран с интерактивной планетой, партнёры, активные лоты, промобаннер и возможности платформы.

## Разработка

Node.js 22.13+ (рекомендуется 24).

```sh
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

TypeScript в строгом режиме, Vite, CSS. Без UI-фреймворка и внешних запросов при загрузке страницы. Шрифт TikTok Sans, изображения и логотипы размещены локально. `base: './'` позволяет публиковать сборку и в корне домена, и по пути `/DPECO/`.

## Структура

- `src/page.ts` — структура страницы и карточки возможностей.
- `src/main.ts` — поиск, фильтры, навигация, модальные окна, доступность.
- `src/lot-cards.ts` — представление лотов.
- `src/data/lots.ts` — типизированные данные лотов.
- `src/styles.css` — токены, компоненты и адаптивы.
- `src/effects/` — интерактивные точки и планета.
- `public/assets/` — иллюстрации, партнёры, бренд и шрифт.

## Данные и интеграции

Лоты, суммы и даты перенесены из предоставленного макета. Они не обновляются с биржи автоматически. Для подключения API замените источник данных в `src/data/lots.ts`, сохранив тип `Lot`, либо добавьте загрузку с явными состояниями ожидания, ошибки и пустого ответа.

Часы в первом экране и шапке показывают текущее московское время. Это не обратный отсчёт до аукциона. Число участников и партнёров — содержание предоставленного макета.

Вход и регистрация ведут на действующие адреса `my.debtprice.market/site/login` и `/site/register`. Кнопки связи открывают контактное окно с телефоном и email площадки; отправки форм и фиктивных сообщений об успешной заявке нет. Ссылка на лот имеет вид `#lot-<id>` и открывает его карточку при загрузке.

## Визуальные компоненты

Точки и географическая планета перенесены из согласованного проекта `IMONsergey/apcoseb-clear`, commit `fd3fedb9d9ca557008994c84ba2b888525090f17`. Движки адаптированы к vanilla TypeScript и палитре DEBTPRICE. Сохранены ограничения частоты кадров и DPI, пауза за экраном/в скрытой вкладке, `prefers-reduced-motion`, Canvas2D fallback для WebGL и освобождение ресурсов.

Стили компонентов используют общие токены, размерности, типографику и состояния управления. Карточки возможностей раскрываются без изменения общей высоты секции; на планшете доступны сеткой, на телефоне — горизонтальной прокруткой. Клавиатура поддерживается в меню, переключателях и диалогах.

## Публикация

Workflow `.github/workflows/deploy.yml` проверяет TypeScript, собирает сайт и публикует `dist` в GitHub Pages после изменений `main`. В настройках Pages источником должна быть выбрана GitHub Actions.

TikTok Sans распространяется по SIL Open Font License; лицензия и сведения об источнике находятся рядом со шрифтом.
