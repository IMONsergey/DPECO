# DEBTPRICE

Сайт платформы и экосистемы долговых активов. Главная, два направления для продавцов, страница покупателей, информация о проекте, документы, контакты, журнал с шестью памятками, заявки и поиск по сайту. Контент основан на ТЗ и материалах заказчика; визуальная система продолжает согласованные решения АПКосис в палитре DEBTPRICE.

## Разработка

Node.js 22.13 или новее. GitHub Actions использует Node.js 24.

```sh
npm ci
npm run dev
```

Проверка типов, сборка и просмотр результата:

```sh
npm run typecheck
npm run build
npm run preview
```

Проект использует TypeScript в строгом режиме, Vite и CSS без UI-фреймворка. Шрифт TikTok Sans, иллюстрации, фотографии и логотипы хранятся в `public/assets/`. Для отображения сайта не нужны внешние CDN. Результат сборки — каталог `dist/`.

## Маршруты

Навигация работает через hash-router: путь находится после `#`, поэтому GitHub Pages не требует серверных перенаправлений для внутренних страниц. `base: './'` позволяет размещать сборку в корне домена или в подкаталоге, например `/DPECO/`.

| Адрес | Содержание |
| --- | --- |
| `#/` | Главная: планета, партнёры, лоты, возможности, форматы торгов, процесс, заявка, экосистема, материалы |
| `#/sellers/portfeli` | Продажа портфелей физических лиц |
| `#/sellers/debitorka` | Продажа дебиторской задолженности юридических лиц |
| `#/buyers` | Покупка долговых активов, лоты и аналитика |
| `#/about` | Проект, команда, история, судебная практика и экосистема |
| `#/docs` | Документы площадки и реквизиты |
| `#/contacts` | Контакты по направлениям и общая заявка |
| `#/journal` | Частые вопросы с фильтрацией по темам |
| `#/journal/sell-company-debt` | Продажа долга юридического лица |
| `#/journal/buyer-registration` | Регистрация участника торгов |
| `#/journal/portfolio-assessment` | Данные для оценки портфеля |
| `#/journal/debt-price` | Факторы цены долгового актива |
| `#/journal/auction-formats` | Форматы торгов |
| `#/journal/transaction-documents` | Документы сделки |
| `#/request` | Подготовка заявки |
| `#/search?q=...` | Поиск по разделам, памяткам и лотам |

Ссылка на отдельный лот имеет вид `#/?lot=triumvirat-20261029` и открывает его карточку в диалоге. Старый формат `#lot-<id>` также распознаётся. Параметр `section` открывает нужный блок после перехода на страницу, например `#/buyers?section=lots`.

Внутри страницы ссылки вида `href="#request" data-scroll="request"` прокручивают к соответствующему `id`, сохраняя текущий маршрут. Неизвестный маршрут получает страницу «Страница не найдена». Заголовок документа обновляется при навигации.

| `src/page-motion.ts`, `src/page-motion.css` | Появление текста и блоков, индикаторы вкладок, движение иллюстраций и смена страниц |

Рендер страниц возвращает HTML. Поведение подключается отдельно и возвращает функции очистки: при смене маршрута удаляются обработчики, таймеры и активные анимации. Общие блоки следует изменять в `sections`, а не копировать в шаблоны направлений.

## Данные и интеграции

### Лоты

В `src/data/lots.ts` находится **8 реальных предложений со снимка [debtprice.market](https://debtprice.market/) на 29 октября 2026 года**: 6 портфелей физических лиц и 2 предложения корпоративной задолженности. Снимок включает аукционы, сбор предложений и проданные лоты; он не является непрерывно обновляемой лентой активных торгов.

Дата проверки (`lotsUpdatedAt`) и источник (`lotsSourceUrl`) указаны рядом с данными. На страницах с лотами и в диалоге показана дата снимка и ссылка на личный кабинет, где доступны текущие условия. API биржи пока не подключён.

Для обновления снимка изменяйте типизированный массив `lots`, дату проверки и соответствующие подписи. Поле `kind` различает аукцион, сбор предложений и проданный лот. Для аукционов `startsAt` содержит ISO-дату с явным часовым поясом. Начальная цена может отсутствовать у сбора предложений. При подключении API необходимо сохранять эти различия и обрабатывать загрузку, ошибку и пустую выдачу.

Фильтры работают по типу актива. Поиск лотов учитывает регистр, `ё/е`, нормализует пробелы и сравнивает слова без построения регулярного выражения из пользовательского ввода.

### Обратный отсчёт

Таймер в шапке и на главной считается **до ближайшего будущего `startsAt` из доступных данных** через `nextAuctionAt()`. Это реальная дата из снимка, а не московские часы и не повторяющийся суточный таймер. Когда в данных больше нет будущих аукционов, отображается «Расписание»; новая дата не выдумывается.

Расчёт использует часы устройства посетителя. В скрытой вкладке обновление приостанавливается и пересчитывается после возвращения. На главной и у покупателей ссылка таймера ведёт к лотам, на остальных страницах — в личный кабинет.

### Заявки и письма

Форма **готовит черновик письма**, а не отправляет заявку на сервер. После проверки полей посетитель видит введённые сведения и может:

- открыть письмо в своей почтовой программе через `mailto:`;
- скопировать текст и отправить его самостоятельно.

Получатель зависит от направления: портфели — `sales@debtprice.market`, корпоративная задолженность — `debt@debtprice.market`, общие заявки и подбор активов — `v@debtprice.market`. При редактировании полей прежний предпросмотр сбрасывается. Сайт не показывает сообщение об успешной доставке: отправку выполняет пользователь из своей почты.

Проверяются обязательные поля, email, телефон, согласие и параметры формы. В оценке корпоративного долга предусмотрены ИНН должника из 10 или 12 цифр и сумма от 500 000 ₽. Данные формы не отправляются через `fetch`, не записываются в хранилище браузера и не передаются в аналитику.

### Внешние сервисы и контент

Вход и регистрация ведут на `my.debtprice.market/site/login` и `/site/register`. Документы открываются по официальным ссылкам `my.debtprice.market`; медиа и продукты экосистемы — на своих сайтах. Отдельного кабинета, платёжного сценария или сервера заявок в этом репозитории нет.

Число участников, партнёров, профессиональные статусы и сведения о судебной практике взяты из материалов заказчика, а не из API. Показатели судебной практики указаны с периодом 2024–2025 годов. Журнал содержит самостоятельные памятки по работе с площадкой без вымышленных дат публикации и времени чтения.

Баннер DEBT TECH 2026 ведёт на `debt-tech.ru` и перестаёт выводиться при рендере с 14 ноября 2026 года, 00:00 МСК.

## Визуальные компоненты

Точки и географическая планета перенесены из согласованного проекта `IMONsergey/apcoseb-clear`, commit `fd3fedb9d9ca557008994c84ba2b888525090f17`. Движки адаптированы к vanilla TypeScript и палитре DEBTPRICE. Сохранены ограничения частоты кадров и DPI, пауза за экраном/в скрытой вкладке, `prefers-reduced-motion`, Canvas2D fallback для WebGL и освобождение ресурсов.

Стили используют общие токены и TikTok Sans разных начертаний. Основной акцент — исходный бирюзовый `#0ba69e`; `#007c77` используется для контрастных управляющих элементов. Обычные поверхности — белые и нейтральные серые. Радиус карточки — 10 px, управляющего элемента — 6 px. Максимальная ширина контейнера — 1440 px, общие интервалы между секциями — 64–96 px. Первые экраны имеют высоту по содержимому; изображения не определяют высоту текстовой строки. Соседние белые секции делят один вертикальный интервал. Главная и страницы направлений имеют тёмный первый экран; тема фиксированной шапки меняется при переходе к светлому содержимому.

Пункты основной навигации постоянно оформлены рамочными кнопками. На ширине 1199 px и меньше они заменяются мобильным меню. Закрытые панели получают `inert` и `aria-hidden`; поддерживаются Escape, стрелки и возврат фокуса. Высота шапки хранится в `--header-height` и учитывает наличие баннера конференции.

**Карточки возможностей увеличиваются внутри сетки на ширине от 1200 px.** Активная карточка растёт по ширине и высоте, соседние уступают место; высота внешней области постоянна и зависит от фактической ширины контейнера: 548–584 px. Геометрия меняется за 660 ms, затем проявляются описание и кнопка. Быстрые наведения отменяют прежнее ожидание; перемещение границ под неподвижным курсором не запускает новые раскрытия. Поддерживаются фокус и клик. При меньшей ширине карточки сразу раскрыты и имеют естественную высоту: две колонки на планшете и горизонтальная лента на телефоне. Переключение роли сохраняет размеры области текста.

Сетка лотов: 4 колонки от 1280 px, 3 от 1000 px, 2 от 700 px; ниже — горизонтальная лента. Обновление фильтров происходит сразу, затем обёртка плавно принимает новую высоту. Повторное переключение продолжает движение с текущего визуального состояния. После завершения анимации фиксированная высота снимается. Вкладки форматов торгов переходят в горизонтальную ленту до 1200 px; форма использует полную ширину до 1100 px и сохраняет два столбца полей до 640 px.

Заголовки появляются через маски с общей задержкой для слов одной строки. Блоки и этапы проявляются последовательно при входе в экран. Индикатор вкладок перемещается под выбранный пункт; диаграммы форматов прорисовываются после появления блока и при переключении. Кнопки имеют мягкое заполнение и направленное движение стрелки. При переходе между страницами View Transitions API сначала убирает старый текст, затем показывает новую страницу; без поддержки API навигация сохраняет обычное поведение. Возврат назад восстанавливает позицию и фильтры. Все эффекты освобождают обработчики и анимации при смене маршрута, учитывают `prefers-reduced-motion`.

Модели цессии и инкассоцессии используют нативные `details`, дополненные плавным раскрытием. Анимации учитывают `prefers-reduced-motion`. Меню, вкладки и диалоги поддерживают клавиатуру. Бегущая строка партнёров непрерывная; при reduced-motion доступна ручная прокрутка.

## Публикация

Workflow `.github/workflows/deploy.yml` устанавливает зависимости через `npm ci`, проверяет TypeScript в составе `npm run build`, собирает сайт и публикует `dist/` в GitHub Pages после изменений ветки `main`. Также доступен ручной запуск workflow. В настройках Pages источником должна быть выбрана GitHub Actions.

Hash-маршруты работают при прямом открытии и обновлении страницы без собственного сервера маршрутизации. Для другого статического хостинга достаточно содержимого `dist/`; адреса личного кабинета и документов остаются внешними.
