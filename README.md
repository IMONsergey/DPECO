## Разработка

Node.js22.13 или новее, TypeScript и Vite. Шрифты и изображения находятся в public/assets; внешний CDN для главной не требуется.

```sh
npm ci
npm run dev -- --host 127.0.0.1
npm run build
npm run preview -- --host 127.0.0.1
```

Сборка включает проверку TypeScript. Рабочая копия: /home/sergey/Projects/DPECO-hover-final-20261112, ветка fix/client-hover-final-20261112. Для тяжелых проверок используется проектная очередь imon-job; разрешенный пользователем срочный обход выполняется отдельным ограниченным systemd job без изменения общих лимитов.

## Данные и незавершенные интеграции

Расписание показывает текущую дату по Europe/Moscow отдельно от даты снимка. Актуальный и архивный наборы происходят из снимков10ноября и29октября2026. Живой API торгов пока не подключен.

Форма проверяет имя, организацию, email, телефон и согласие. Код телефона подбирается по timezone/locale браузера; ручной международный код сохраняется. Форма готовит локальный черновик и прямо сообщает, что заявка не отправлена.

Реальная доставка в Telegram/CRM требует серверного обработчика, настроенного бота и определенного получателя. В текущем проекте этих настроек нет. Ссылка на Telegram-канал не является endpoint доставки. Успешное состояние нельзя показывать до подтвержденной отправки. Проверки не отправляют сообщения и заявки внешним получателям.

Privacy содержит официальный PDF embed и прямую ссылку https://my.debtprice.market/Privacy_policy.pdf. Это не самостоятельная HTML-копия юридического текста.

## Приемка и публикация

CHECKPOINT.md содержит текущий статус, точные версии, публикации и оставшиеся пункты. Старые отчеты и CI93 относятся к своим исходным версиям; их нельзя выдавать за приемку новой разрешенной навигации.

Правка доступности опубликована 12.11 в 20:36 МСК. check-client-availability-20261112.mjs: 16/16 PASS, 1440 light / 390 dark, 13 целевых элементов, hover/touch/focus/Enter/Escape, прямые закрытые hash, Privacy и поиск. publish-client-availability-20261112.py закрепляет этот отчет и baseline625f6f2a; verify-client-availability-20261112.py подтвердил 138/138 HTTP/SHA, 102 файла и 34 запрещенных пути. Публичный HTML4da0f5e9, JS index-B_1Lktz4.js. Ведомость: qa/homepage/acceptance-availability-20261112.json.

Историческая приемка новых переходов: qa/homepage/check-client-links-20261112.mjs. Адаптив и переходы на320/390/768/1440: qa/homepage/check-client-mobile-20261112.mjs. Тесты используют изолированные Chromium-контексты, блокируют внешние запросы и сетевые записи, сохраняют исходные отчеты и снимки. Проверка headless Chromium не означает проверку нативного Safari.

Для срочной публикации созданы отдельные publish-client-links-20261112.py и publish-client-mobile-20261112.py. Они закрепляют конкретные passing-report/script SHA, source/public/dist, проверяют исходные6QA/gate-файлов и текущий публичный baseline, затем атомарно меняют корень с полным backup. После обмена отдельные verify-client-* проверяют HTTP и SHA всех опубликованных файлов. Эти драйверы привязаны к конкретным выпускам и не являются командой безусловного повторного deploy.
