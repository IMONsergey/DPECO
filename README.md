# DEBTPRICE — главная

Одна главная страница платформы и экосистемы долговых активов. Опубликованный адрес: https://debtprice.imon.world/.

Объем по поручению 11 ноября 2026: сохранить актуальный макет Page 10, исходную графику, интерактивные эффекты и темную тему; оставить только главную; опубликовать на отдельном поддомене. Вторичные страницы не создаются и не доступны через маршрутизатор.

Эталон: [Figma, Page 10, master 391:827](https://www.figma.com/design/s1OW0lfbe6GaUqhrKlHDrK/?node-id=391-827). Приоритетные комментарии: [итоговый разбор заказчика](https://docs.google.com/document/d/1h6WWx_T6NinJ2dZ-Yyn-fQqVGNi9La4imwuzvNVotd4/edit).

## Разработка

Node.js 22.13 или новее, TypeScript и Vite. Шрифты, иллюстрации и логотипы находятся в `public/assets/`; внешний CDN для отображения сайта не нужен.

```sh
npm ci
npm run dev -- --host 127.0.0.1
npm run typecheck
npm run build
npm run preview -- --host 127.0.0.1
```

Сборка включает проверку TypeScript; результат — `dist/`. На IMON Workstation сборки и браузерные проверки выполняются через очередь `imon-job`, например:

```sh
imon-job submit --cwd /home/sergey/Projects/DPECO-home --timeout 300 -- npm run build
imon-job submit --cwd /home/sergey/Projects/DPECO-home --timeout 900 -- node qa/homepage/check-homepage.mjs
```

## Навигация

Главная монтируется один раз. Меню и кнопки переходят к секциям; сведения о лоте, форматы торгов, поиск и документы открываются в диалогах. Назад/вперед восстанавливают позицию и фокус. Поиск работает локально по разделам и проверенному снимку лотов.

| Адрес | Назначение |
| --- | --- |
| `/`, `#top` | Начало главной |
| `#lots` | Расписание торгов |
| `#sell-buy` | Выбор продажи или покупки |
| `#capabilities` | Возможности платформы |
| `#formats` | Форматы торгов |
| `#process` | Этапы работы |
| `#request` | Консультация и подготовка заявки |
| `#ecosystem` | Проекты экосистемы |
| `#materials` | Полезные материалы |
| `#documents` | Диалог официальных документов |

Старые входящие адреса `#/buyers`, `#/sellers/portfeli`, `#/sellers/debitorka`, `#/about`, `#/contacts`, `#/journal`, `#/request`, `#/docs` ведут к соответствующему разделу главной или диалогу. Поддерживаются `#/?section=ecosystem`, `#/search?q=...`, `#/?lot=<id>` и `#lot-<id>`. Отдельных страниц по этим адресам больше нет. Неизвестный hash возвращает к главной; неизвестный HTTP-путь на опубликованном домене получает 404.

## Данные и интеграции

**Торги.** Расписание содержит шесть лотов на 11–13 ноября из снимка 10 ноября 2026. Архив использует отдельный снимок 29 октября. Дата данных видна в расписании и деталях лота. Таймер учитывает московское время; после истечения всех известных стартов страница не выдает прошлые торги за ближайшие. API торгов пока не подключен.

**Заявка.** Форма проверяет поля и согласие на обработку данных, затем показывает почтовый черновик для проверки. Отправка в Bitrix24 или другой CRM отсутствует. Кнопки открытия почты и копирования текста не обозначаются подтверждением отправки. Выбранное направление продажи/покупки передается в черновик. Общее обращение сбрасывает специализацию предыдущего выбора.

**Внешние действия.** Вход и регистрация ведут на `https://my.debtprice.market/site/login` и `/site/register`. Шесть официальных документов открываются на `my.debtprice.market`; продукты экосистемы — на своих сайтах. Проверка документов 11 ноября 2026 подтвердила HTTP 200 и сигнатуры PDF/XLSX. Профессиональные статусы и деловые показатели взяты из предоставленных материалов; независимая юридическая проверка этих утверждений не заявляется.

## Визуальное поведение и доступность

Сохранены географическая планета, интерактивные точки, появления текста и секций, движение иллюстраций, раскрытие карточек, вкладки и графики форматов торгов. Эффекты приостанавливаются вне экрана, поддерживают `prefers-reduced-motion` и не блокируют основной контент. Кнопки, меню, вкладки и диалоги поддерживают клавиатуру, Escape и возврат фокуса.

Темная тема переключается в шапке и сохраняется после перезагрузки. Оригинальные изображения и композиция Page 10 сохранены в обеих темах. TikTok Sans и Manrope хранятся локально; сведения об источниках и лицензиях находятся в `public/assets/fonts/`.

## Приемка и публикация

Актуальное состояние и точные версии записываются в `CHECKPOINT.md` и `qa/homepage/`. `PAGE10_NOTES.md` и `qa/page10/` описывают историческую проверку предыдущей версии, а не текущую приемку.

Браузерный стенд запускает отдельные headless-контексты Chromium, Firefox и WebKit, обслуживает `dist/` только на loopback и блокирует исходящие запросы кроме GET/HEAD. Проверяются реальные действия, обе темы, ширины 1440, 390 и 320 px, документы, валидация формы и истекшее расписание. Проверка WebKit не означает проверку нативного Safari.

Публикация: статическая сборка через Nginx и HTTPS на `debtprice.imon.world`, версия в `/srv/debtprice/releases/`, атомарная ссылка `/srv/debtprice/current`. Домен закрыт от поисковой индексации. Источник — ветка `feat/homepage-only-20261111`, рабочая копия `/home/sergey/Projects/DPECO-home`.

Существующий GitHub Pages workflow по-прежнему относится к ветке `main`; публикация новой главной на отдельном поддомене не требует ее слияния. Боевой `debtprice.market` и прежняя галерея `debtprice-lab.imon.world` не входят в эту публикацию.
