# Главная DEBTPRICE — редакция 07.11.2026

Статус: рабочая дизайн-итерация, не утвержденный прототип и не боевой релиз.

## Источники

- Идеи заказчицы: <https://debtprice-content-edits.vercel.app/doc/> (10 блоков главной, сырой контент).
- Визуальная система: существующая сборка [DPECO](https://github.com/IMONsergey/DPECO), шрифт TikTok Sans, бирюзовая палитра, глобус из точек, белые поверхности, радиусы и компоненты.
- Память: навык `debtprice-imon` и плагин DebtPrice Memory.

## Реализовано в этой итерации

1. Новый первый экран с конкретной ролью ЭТП, типографической иерархией, глобусом и двумя самостоятельными сценариями «Продавцу / Покупателю».
2. Две ветки продавца с отдельными CTA; участие в торгах ведет на реальную торговую площадку.
3. Расписание/лоты перенесены выше партнеров; повторный промоблок покупателей удален.
4. Возможности, форматы торгов, схема сделки, заявка, экосистема и материалы сохраняют единую систему DPECO.
5. В возможностях уточнена категория «Прочие права требования»; в блоке материалов поправлена семантика (это статьи, а не FAQ).
6. Домашняя форма использует поля организации/ИНН/КПП и отдельное необязательное рекламное согласие; до подключения CRM она формирует письмо и честно обозначает это.
7. Непроверенные числовые рекламные утверждения на главной не повторяются, фиктивные реквизиты из клиентского документа не переносились.
8. Избыточная ссылка «Дебиторская задолженность» в шапке удалена из верхнего уровня: раздел остается доступен через «Продавцам».

## Еще не готово и не должно имитироваться

- В этой версии нет подтвержденного API торгов. В карточках старые данные по состоянию на 29.10.2026; видимое предупреждение сохранено. Нельзя обозначать их актуальным расписанием.
- Вкладки «Предстоящие / За прошлый месяц», режим «Физлица / Юрлица» и таблица с живыми статусами потребуют API/контракт с данными. Не подменять фиктивными лотами.
- Bitrix24/Telegram для формы не подключены; это не полноценная отправка заявки.
- Юридические данные, статусы Сколково/НСФР/ТПП/НАПКА, «крупнейшая», «500+ компаний» и партнерские логотипы требуют подтверждения клиентом.
- «Инвесторам» не имеет согласованной самостоятельной страницы. Реальные публикации журнала и все юридические тексты нуждаются в сверке.
- Новые маршруты и прямые URL без hash следует реализовать перед переездом с GitHub Pages на основной домен.
